Fig. A / Foundation

Principles

Six ideas the whole system leans on. Every token and component below is a consequence of one of them.

Type is the layout

Big grotesque headlines and a strict grid do the design work. Decoration stays out of the garment’s way.

Warm paper, deep ink

A bone-white canvas and near-black ink give the store its editorial, printed-catalog warmth.

Metadata is monospace

Prices, sizes, SKUs and labels are set in mono with wide tracking — like a spec sheet or a care tag.

One electric accent

Cobalt carries every call to action, link and focus ring. Product colorways supply the rest of the palette.

Sharp, printed corners

Radii stay small (2–4px). Softness comes from space and photography, never from rounded boxes.

Restrained motion

A marquee, a hover reveal, a quick fade. Nothing that gets between the shopper and the product.

Fig. I / Usage

Using the tokens

The system ships as CSS custom properties and a React kit. Drop the stylesheet in, wrap a subtree in .of, and compose.

/* 1 · import the token layer */
import './styles/outfit-tokens.css';

/* 2 · reference any token */
.price {
  font: var(--of-price);
  color: var(--of-ink);
}
// 3 · or use the React kit
import { Button, ProductCard }
  from './design-system/OutfitKit';

<div className="of">
  <Button variant="accent">Checkout</>
</div>
